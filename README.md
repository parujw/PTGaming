# เศรษฐีบางกอก 🛺

เกมเศรษฐีฉบับกรุงเทพฯ สายฮา: ซื้อที่ดินตั้งแต่คลองเตยถึงสยามพารากอน เจอการ์ด "หมอดูทัก" กับ "ดราม่าโซเชียล" มุกการเมือง ดารา หอแต๋วแตก The Face และมีมที่คนไทยรู้จัก

## วิธีเล่น
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

- เล่นบนเครื่องเดียว 2–4 คน ผสมคนกับบอทได้
- ทุนเริ่มต้น ฿15,000 ผ่านจุดเริ่มต้นรับเงินเดือน ฿2,000
- ได้ที่ดินครบสี ค่าเช่า ×2 และสร้างคอนโด (สูงสุด 4) แล้วอัปเป็นห้าง
- "ฝนตก รถติด!" = ไปติดแยกอโศก ออกได้ด้วยดับเบิ้ล จ้างวินซิ่ง ฿500 หรือใช้ "ตั๋วช้าง"
- เงินไม่พอจ่าย ระบบขายสิ่งปลูกสร้างและจำนองให้อัตโนมัติ ถ้ายังไม่พอคือล้มละลาย
- ชนะเมื่อเหลือคนเดียว หรือครบจำนวนรอบที่ตั้งไว้แล้วนับทรัพย์สินรวม

## ระบบช่วยเล่น (automation)
- ทอยครั้งเดียว ระบบเดินหมาก คิดค่าเช่า ภาษี เงินเดือน และตรวจผู้ชนะให้ทั้งหมด
- ปุ่มหลักเปลี่ยนตามสถานการณ์: ทอยเต๋า → ซื้อ ฿X → จบตา ปุ่มถูกล็อกระหว่างเดินหมากกันกดซ้ำ
- ก่อนซื้อบอก ราคา · ค่าเช่า · เงินหลังซื้อ · จะครบสีหรือยัง
- ปุ่มสร้างคอนโดที่กดไม่ได้จะบอกเหตุผล เช่น "ต้องมีครบสีก่อน (1/2)" หรือ "เงินไม่พอ ขาดอีก ฿X"
- เงินไม่พอจ่าย: บอก "ขาดอีก ฿X" ให้เลือกขาย/จำนองเอง (ปุ่มบอกเงินที่จะได้และผลเสีย) หรือให้ระบบจัดการให้ หรือยอมล้มละลาย
- บันทึกเกมอัตโนมัติ (โหมดเครื่องเดียว) ปิดหน้าแล้วกลับมากด "เล่นต่อ" ได้
- จบเกมสรุปอันดับ เงินสด ทรัพย์สิน และมูลค่ารวม

## โหมดมีมไทยและเอฟเฟกต์
มุกแต่งขึ้นใหม่สำหรับเกม (ไม่ใช่คำพูดจริงของบุคคล) 4 แพ็ก: The Face / ตัวแม่, หอแต๋วแตก, การเมือง (แถลงข่าวด่วน), ดารา / ข่าวบันเทิง
- มุกขึ้นตามเหตุการณ์: ซื้อครบสี, เสียค่าเช่าแพง, เงินเหลือน้อย, จำนอง, ติดแยกอโศก, สร้างห้าง, รอดเฉียดๆ, ล้มละลาย, ชนะ ฯลฯ
- 3 ระดับ: เบา (ฟองข้อความสั้น), กลาง (การ์ดรีแอ็กชันพร้อมสปอตไลต์/กรี๊ด+จอสั่น/แถบข่าวด่วน/แฟลชกล้อง เว้น 20 วินาทีระหว่างการ์ด), ใหญ่ (ฉากล้มละลาย, มงกุฎ+พลุตอนชนะ)
- ไม่ใช้มุกเดิมซ้ำใน 5 ครั้งล่าสุด เห็นผลเกมก่อนแล้วมุกตามมา คลิกเพื่อปิดได้
- ⚙️ ตั้งค่า (เฉพาะเครื่องนี้): เสียง, ความเร็วเกม, ลดการเคลื่อนไหว, ระดับมีม (จัดเต็ม/พอดี/ปิด), เลือกแพ็กมีม
- เพิ่ม/แก้มุกได้ที่ตัวแปร `MEMES` (แต่ละบรรทัดมี เหตุการณ์ แพ็ก ข้อความ และเดือนที่เพิ่ม)

## เสียงประกอบ
เสียงทั้งหมดสร้างสดด้วย Web Audio (ไม่มีไฟล์เสียง) ได้แก่ ทอยเต๋า เดิน ได้เงิน จ่ายเงิน ซื้อที่ สร้างคอนโด เปิดการ์ด ติดแยกอโศก ล้มละลาย ชนะ และเสียงเตือนเมื่อถึงตาเรา กดปุ่ม 🔊 ในกล่อง "ตาเดิน" เพื่อปิด/เปิดเสียง

## เล่นออนไลน์ข้ามเครื่อง
ใช้ได้เมื่อเปิดเกมผ่านลิงก์ artifact บน claude.ai (ไฟล์ที่เปิดจากเครื่องเล่นได้แค่แบบเครื่องเดียว)
1. เจ้าของแชร์ artifact ให้เพื่อนเป็น Contributor ขึ้นไป (สิทธิ์ดูอย่างเดียวเข้าชมได้แต่เล่นไม่ได้)
2. คนหนึ่งกด "เล่นออนไลน์" → "สร้างห้องใหม่" จะได้รหัส 4 ตัว
3. เพื่อนเปิดลิงก์เดียวกัน กด "เล่นออนไลน์" แล้วใส่รหัส หรือเลือกจากรายการห้องที่รอผู้เล่น
4. เจ้าของห้องเพิ่มบอทได้ เลือกจำนวนรอบ แล้วกดเริ่มเกม

สถานะเกมเก็บในฐานข้อมูลของ artifact (`games/<รหัสห้อง>`) เฉพาะคนที่ถึงตาเป็นคนบันทึก บอทรันบนเครื่องเจ้าของห้อง ถ้าใครหลุด เจ้าของห้องกด "ให้บอทเล่นแทน" ได้ ปิดหน้าไปแล้วกลับมากด "กลับเข้าห้อง" ได้ ระหว่างรอเทิร์นกดส่งรีแอ็กชัน (เริ่ด / งงมาก / เจ๊ไม่ไหว ฯลฯ) ให้ทุกคนในห้องเห็นได้

## แก้เนื้อหา
ข้อมูลทั้งหมดอยู่ในตัวแปรด้านบนของ `<script>` ใน `index.html`
- `TILES` ช่องบนกระดาน (ชื่อ ราคา ค่าเช่า คำบรรยาย)
- `CHANCE` การ์ดหมอดูทัก / `CHEST` การ์ดดราม่าโซเชียล
- `TOKENS` ตัวเดิน, `DEFAULT_SLOTS` ผู้เล่นเริ่มต้น
