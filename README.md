# เศรษฐีบางกอก 🛺

เกมเศรษฐีฉบับกรุงเทพฯ สายฮา: ซื้อที่ดินตั้งแต่คลองเตยถึงสยามพารากอน เจอการ์ด "หมอดูทัก" กับ "ดราม่าโซเชียล" มุกการเมือง ดารา หอแต๋วแตก The Face และมีมที่คนไทยรู้จัก

## วิธีเล่น
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

- เล่นบนเครื่องเดียว 2–4 คน ผสมคนกับบอทได้
- ทุนเริ่มต้น ฿15,000 ผ่านจุดเริ่มต้นรับเงินเดือน ฿2,000
- ได้ที่ดินครบสี ค่าเช่า ×2 และสร้างคอนโด (สูงสุด 4) แล้วอัปเป็นห้าง
- "ฝนตก รถติด!" = ไปติดแยกอโศก ออกได้ด้วยดับเบิ้ล จ้างวินซิ่ง ฿500 หรือใช้ "ตั๋วช้าง"
- เงินไม่พอจ่าย ระบบขายสิ่งปลูกสร้างและจำนองให้อัตโนมัติ ถ้ายังไม่พอคือล้มละลาย
- ชนะเมื่อเหลือคนเดียว หรือครบจำนวนรอบที่ตั้งไว้แล้วนับทรัพย์สินรวม

## เสียงประกอบ
เสียงทั้งหมดสร้างสดด้วย Web Audio (ไม่มีไฟล์เสียง) ได้แก่ ทอยเต๋า เดิน ได้เงิน จ่ายเงิน ซื้อที่ สร้างคอนโด เปิดการ์ด ติดแยกอโศก ล้มละลาย ชนะ และเสียงเตือนเมื่อถึงตาเรา กดปุ่ม 🔊 ในกล่อง "ตาเดิน" เพื่อปิด/เปิดเสียง

## เล่นออนไลน์ข้ามเครื่อง
ใช้ได้เมื่อเปิดเกมผ่านลิงก์ artifact บน claude.ai (ไฟล์ที่เปิดจากเครื่องเล่นได้แค่แบบเครื่องเดียว)
1. เจ้าของแชร์ artifact ให้เพื่อนเป็น Contributor ขึ้นไป (สิทธิ์ดูอย่างเดียวเข้าชมได้แต่เล่นไม่ได้)
2. คนหนึ่งกด "เล่นออนไลน์" → "สร้างห้องใหม่" จะได้รหัส 4 ตัว
3. เพื่อนเปิดลิงก์เดียวกัน กด "เล่นออนไลน์" แล้วใส่รหัส หรือเลือกจากรายการห้องที่รอผู้เล่น
4. เจ้าของห้องเพิ่มบอทได้ เลือกจำนวนรอบ แล้วกดเริ่มเกม

สถานะเกมเก็บในฐานข้อมูลของ artifact (`games/<รหัสห้อง>`) เฉพาะคนที่ถึงตาเป็นคนบันทึก บอทรันบนเครื่องเจ้าของห้อง ถ้าใครหลุด เจ้าของห้องกด "ให้บอทเล่นแทน" ได้ ปิดหน้าไปแล้วกลับมากด "กลับเข้าห้อง" ได้

## แก้เนื้อหา
ข้อมูลทั้งหมดอยู่ในตัวแปรด้านบนของ `<script>` ใน `index.html`
- `TILES` ช่องบนกระดาน (ชื่อ ราคา ค่าเช่า คำบรรยาย)
- `CHANCE` การ์ดหมอดูทัก / `CHEST` การ์ดดราม่าโซเชียล
- `TOKENS` ตัวเดิน, `DEFAULT_SLOTS` ผู้เล่นเริ่มต้น
